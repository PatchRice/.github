# Support / 使用支持

For a reproducible defect, choose **Bug report**. For a usage or setup question, choose **Question**. For changes to existing behavior or new functionality, choose **Feature request**.

对于可复现的异常请使用 **Bug report**；使用或配置疑问请使用 **Question**；新功能与行为改进请使用 **Feature request**。

If the repository has GitHub Discussions enabled, use it for open-ended questions and conversations. Avoid sharing credentials, personal information, private data or sensitive logs publicly. Security vulnerabilities must be reported using the private channel in [SECURITY.md](SECURITY.md).

如果仓库启用了 Discussions，开放式讨论可优先在那里发起。公开内容请先脱敏；安全漏洞参照 [SECURITY.md](SECURITY.md) 私密报告。
